## MEP | Meat Puppet Elimination Protocol

A state relay for stateless AI sessions.  Stops a human being used as the message bus between machines.

| Document | What |
|----------|------|
| [**Overview**](/protocol/) | Problem-first landing page.  Why it exists, the four components, quick start, proof it works.  Start here. |
| [**Specification**](/docs/mep-protocol/) | Full technical spec, version 2.4.  Design principles, implementation, production milestones.  Includes the nine minute audio explainer. |
| [**Handoff Schema**](/docs/mep-handoff-schema/) | The formal schema for the handoff file itself.  What the three sections contain and how they are validated. |
| [**MEEP-ReadOnly-v1**](/docs/meep-readonly-v1/) | Read-only context surface for peer agents outside the repo.  Public, unlinked, no return path. |
| [**Lexicon**](/docs/mep-lexicon/) | The vocabulary.  Borrowed from oil rigs, recontextualised for stateless machines. |

## ARP | Agent Retirement Protocol

How to remove an agent without leaving its instructions behind to be followed by something that no longer exists.

| Document | What |
|----------|------|
| [**Specification**](/docs/arp-protocol/) | Archive, do not delete.  Sweep the instruction pile, keep the record. |
